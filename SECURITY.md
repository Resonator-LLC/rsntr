# Security

Please do not report security problems in public issues.

Report them privately through GitHub: on
<https://github.com/Resonator-LLC/rsntr/security>, choose **Report a
vulnerability**. We answer within a few days, agree on a fix and a date
with you, and credit you in the release notes unless you prefer not.

In scope: the `resonator` server and node, `resonator-push`, the web
client, the iOS and Android apps, and the official servers (`rsntr.net`,
`resonator.network`, `rly.rsntr.net`, `psh.rsntr.net`). Do not run
denial-of-service tests or access other people's data on the official
servers; a test account of your own is enough.

Fixes go into the latest release only.
