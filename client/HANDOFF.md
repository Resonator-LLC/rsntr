## The brief (short form)

Build the SPA on top of the existing client core: shell (sign-in, registration, top bar, two-pane layout, waveref routing), search panel, wave panel (threads, focus frame, read state, participants, tags), rich-text OT editor, profiles/avatars, accessibility, Wave-like modern design. Strict CSP (`default-src 'self'`): no inline scripts or `style="…"` attributes, no innerHTML with user data, no third-party requests. Preact + `@preact/signals` for chrome; the editor is hand-written DOM. Playwright e2e against the real server binary; screenshots to `/tmp/claude-1000/-home-rafael-resonator/829b1b22-d69c-41c2-8cfa-79a908ad2e86/scratchpad/ui/screens/` (none taken yet).

## Layout and contracts (done, by the lead)

- `package.json`: runtime deps `preact`, `@preact/signals`; dev deps `@preact/preset-vite`, `happy-dom`, `@playwright/test` (Chromium headless shell downloaded and verified to launch).
- `vite.config.ts`: Preact preset; dev/preview proxy of all API paths and the `/socket` WebSocket to `RESONATOR_BACKEND` (default `http://127.0.0.1:9898`); `assetsInlineLimit: 0`; tests include `*.test.tsx`.
- `tsconfig.json`: JSX for Preact; includes `e2e/` and `playwright.config.ts`.
- `playwright.config.ts`: `testDir: e2e`, `*.spec.ts`, 1 worker.
- `index.html` loads `/src/ui/main.tsx`; `public/favicon.svg`.
- `src/ui/contracts.ts`: `Route`, `WavePanelProps`, `SearchPanelProps` (shell ↔ panels).
- `src/ui/editor/api.ts`: the editor contract (`EditorDocument`, `BlipView`, `EditorCommand`, `EditorState`, `AnchorHost`, `AttachmentSource`). Additive changes only.
- `src/ui/profiles/profileStore.ts`, `Avatar.tsx`: batched `/profile` fetch, signal-backed. Untested.
- `src/ui/styles/tokens.css`, `base.css`: the design system (light/dark, buttons, inputs, dialog, menu, avatar, badge).
- `e2e/app/support/servers.ts`: starts the real binary plus a static server for `dist/` that proxies API paths and the WebSocket and sends the server's CSP. Compiles; never run.
